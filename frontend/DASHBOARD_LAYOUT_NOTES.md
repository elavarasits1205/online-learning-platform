# Dashboard layout notes

The instructor dashboard now uses the space below the course list for three
useful next steps: building a course curriculum, reviewing course activity,
and supporting learners in the community.

When adding dashboard content later:

- Use the empty area for actions or insights that help the instructor decide
  what to do next.
- When a metric has no data, explain why and offer a relevant next step instead
  of stretching an empty chart or leaving a blank card.
- Keep a clear reading order: summary metrics, teaching insights, course list,
  then optional actions.
- Keep action cards in a responsive grid so they stack on narrow screens.
- Let healthy whitespace separate sections; avoid filling it with decorative
  widgets that do not help teaching or course management.
